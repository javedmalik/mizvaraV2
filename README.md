# MIZAVARA Global V2.0 — Catalogue website

Full consolidated Next.js source, based on original project and approved desktop/mobile references. No cart, prices, account, payment or database. Existing Formspree and WhatsApp configuration retained.

## Run locally (Node.js 20.9+; Node 22 recommended)

```powershell
npm install
npm run dev
npm run typecheck
npm run build
```

Open http://localhost:3000. Run `npm run start` after a successful build. The dependency lockfile will be generated by npm install; registry access is required. Google fonts are fetched by Next.js at build time. Do not copy node_modules or .next from the old project.

## Pages
Home, catalogue, individual product and category details, About, Wholesale, Distributor, Contact, Privacy, Terms, Shipping & Returns, Services and Export & Import. Existing category routes retained. Dry Fruits is an enquiry-only category.
